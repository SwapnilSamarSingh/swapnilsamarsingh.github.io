# Data With Swapnil — portfolio starter

A responsive, static portfolio skeleton built with HTML, CSS, and JavaScript. No build tools or paid services are required.

## Files
- `index.html` — all page content and sections
- `styles.css` — design system, responsive layouts, themes, and animations
- `script.js` — theme toggle, mobile navigation, project filters, reveal animations, and current year
- `assets/` — place your resume PDF and any future local images here

## Preview locally
1. Extract the ZIP if needed.
2. Open `index.html` in Chrome, Edge, Firefox, or Safari.
3. Test the dark-mode switch, navigation, and project filters.

## Publish with GitHub Pages
1. Create a **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io`.
2. Upload `index.html`, `styles.css`, `script.js`, `README.md`, and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/ (root)`, then save.
6. After the deployment finishes, visit `https://YOUR-GITHUB-USERNAME.github.io`.

## Before sharing publicly
- Replace the sample copy with accurate details.
- Update the placeholder email and links.
- Add only skills you can confidently discuss.
- Add your real resume as `assets/resume.pdf` before creating a resume download link.
- Do not put passwords, API keys, private datasets, or sensitive personal information in this public repository.

## Notes
- The project cards are explicitly placeholders, not claims about completed projects.
- The sample chart is illustrative, not real performance data.
- The Google Fonts import is optional; the page falls back to common sans-serif fonts if the service is unavailable.
